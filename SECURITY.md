# Security

Do not expose ser2net, OTBR REST, ESPHome management, MQTT or Z-Wave JS to the
Internet. Scope access to the trusted controller network. Use unique ESPHome API
encryption and OTA credentials. Runtime examples must be adapted to the LAN firewall.

Report vulnerabilities without disclosing installation secrets. Use GitHub's
private vulnerability reporting if enabled; otherwise contact the repository owner
privately before filing details publicly. Do not post real radio network backups.
